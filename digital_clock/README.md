#  Digital Clock

A simple and modern digital clock built using Python and PyQt5.

##  Features

-  Real-time clock
-  Updates every second
-  Digital-style font
-  Green clock display
-  Black background
-  GUI-based application

##  Technologies

- Python
- PyQt5
- QTimer
- QTime
