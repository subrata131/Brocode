#  Python Alarm Clock

A simple alarm clock built using Python and Pygame.

## Features

-  Set alarm using HH:MM:SS
-  Plays music when alarm starts
-  Two songs play continuously
-  Press `S` to stop the alarm
-  Uses Pygame for audio

##  Technologies

- Python
- Pygame
- Datetime
- Time
